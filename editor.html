CPC SPRITE STUDIO MANUAL

1. Project Management & Basic Setup

  • Save/Load Project JSON: Use the Floppy Disk and Folder icons on the top left, or press Ctrl+S to Quick Save. Saves the workspace configuration and all pixels. Example: Make a backup of your character sheet before making destructive palette changes.
  • Multi-Sprite Tabs: Use the '+' button in the top tab bar to add multiple sprites to your project. Double-click a tab to rename it, and drag and drop tabs to reorder them!
  • Undo Ctrl+Z: Reverts your last drawing action or transformation (up to 50 states).
  • Canvas Dimensions: Change width (`DIM: x`) and height (`DIM: y`). The canvas dynamically recalculates the bytes needed depending on the selected CPC Mode.
  • Amstrad CPC Video Modes:
    • Mode 0: 16 Colors. Wide pixels (1 byte = 2 pixels).
    • Mode 1: 4 Colors. Square pixels (1 byte = 4 pixels).
    • Mode 2: 2 Colors. Thin pixels (1 byte = 8 pixels).

2. Drawing Tools

  • Pen P: Default freehand drawing tool. Click and drag to paint with the selected color from the bottom palette.
  • Line /: Click, drag, and release to draw a straight line between two points.
  • Box R: Draws an empty rectangle. Click the starting corner and drag to the opposite corner. Example: Creating structural walls for a maze game.
  • Circle C: Draws a perfect circle outline.
  • Paint Bucket G: Fills an enclosed area of the same color with the currently selected color.
  • Color Picker I: Click on any pixel to select its color for the active mouse button.
  • Select Fragment S: Click and drag to select a specific rectangular area. Press Ctrl+C to copy, and Ctrl+V to paste it anywhere on the canvas.
  • Text Tool T: Click anywhere to type text directly onto the canvas. Allows dynamic font resizing and auto-spill over frames.
  • Hide Grid: Check the "Hide Grid" box on the top toolbar to remove the grid lines and preview your sprite as it will look on a real CRT.

3. Animation & Frame Control

  • Add Frame (+F) / Remove Frame (-F): Injects or deletes a new blank frame in a specific position of your sequence.
  • Animate Button: Opens a floating window reproducing your sprite sequence. You can drag the window, scroll to zoom in/out, and press + or - to increase/decrease the animation speed (ms per frame).

4. Transformations & Canvas Shifting

  • Mirror H / V: Flips the sprite horizontally or vertically. You can apply it to the entire sequence or just a single specific frame. Example: Drawing a character facing right, then duplicating the frame and applying Mirror H to make them face left.
  • Rotate 90º Q: Rotates the canvas data by 90 degrees clockwise.
  • Fix M0 Width: Special tool for Mode 0. It halves the canvas width, compressing the pixels. Example: You drew a 32-width Mode 0 sprite, but CPC Mode 0 pixels are double-width, meaning you only needed 16 bytes. This fixes it instantly without redrawing.
  • Shift Mode ✥: Click this to activate. When active, use the Keyboard Arrow keys to nudge the pixels of the currently hovered frame 1 pixel in any direction. Example: Fixing a sprite that was drawn slightly off-center without redrawing it.
  • Full Sprite Shift Checkbox: If checked, using the arrow keys will move the content of ALL frames simultaneously instead of just the hovered one.

5. Palette & Hardware Colors

  • Palette Manager PAL: Opens the CPC Hardware Color list. Select a color swatch at the bottom, then click here to replace it with a true Amstrad CPC hardware color (0-26). You can also instantly copy the current palette to your clipboard (CSV or ABASC INK format) using the buttons here!
  • Custom Palette Import: Inside the PAL menu, you can paste raw data values (e.g., `0x54, 0x4B`) to automatically replace your current palette based on existing game code.

6. Import & Export Options

  • Paste from Clipboard: Click the clipboard icon, then press Ctrl+V to paste an external image. A dialog will ask if you want to auto-generate the best palette for the image, or map colors to your current palette. Tip: Check "Ignore Ink 0 on Paste" to preserve your canvas background (it skips any pixel that maps to Ink 0 or is fully transparent).
  • Import Code (ABASC / 8BP / C): Paste ASM code (`DB`, `DEFB`), BASIC `DATA` lines, or C Arrays (`{0x00, 0xFF}`). The engine automatically decodes the bytes and draws them onto the canvas.
  • Import SCR & ALFABET: Use Import SCR to load graphics from 16KB Amstrad memory dumps. Use ALFABET to manage 1-bit/px monochrome fonts (8 pixels per byte).
  • Export Menu:
    • Decimal values: Checkbox to export values as decimal numbers instead of hexadecimal (for ASM and C).
    • 8BP ASM: Exports row-aligned Assembler code ready for 8BP or standard Z80 dev.
    • Download .BIN: Raw binary memory dump of the screen.
    • Download .DSK: Generates a bootable floppy disk with a BASIC loader. You can choose Animated (hardware loop) or Static Frame Strip. Note: The editor will warn you if your sprites exceed the ~26KB continuous RAM limit of a standard 64K CPC!
    • ABASC DATA: Exports structured `DATA` lines using Words for the ABASC compiler, including the INK commands for easy copy-pasting.
    • C Array: Exports a C-compatible array (`{0x00...}`) separated by frames (`sprite_data00`, etc.).
